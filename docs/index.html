First transfer
  1. Install Dispatch on both computers.
  2. On the receiving computer, open Dispatch and click Start listening.
  3. On the sending computer, pick the device in the list, choose a file and click Send.
  4. The first time two computers meet, both screens show a 6-digit code. Click Codes match only if the codes are identical.
What it does
  • Every transfer is encrypted and mutually authenticated. There is no unencrypted mode.
  • If a trusted device turns up with a different key, Dispatch refuses it and warns you.
  • Files move in 4 MiB blocks. Each block is checked, then the whole file is checked at the end.
  • Speed is the speed of your network. On a 100 Mbps link that is about 11 MB/s. Going beyond that needs gigabit Ethernet at both ends.
Before you install
  • Windows may say Windows protected your PC, because the installer is not code-signed yet. Choose More info, then Run anyway.
  • Windows Firewall: allow Dispatch on Private networks when it asks.
  • Both computers must be on the same network, or joined by a cable. Dispatch uses UDP 47600 and TCP 47601.
Check your download

Compare the hash of the file you downloaded with SHA256SUMS.txt from the same release.

# Linux
sha256sum Dispatch_*.deb

# Windows (PowerShell)
Get-FileHash .\Dispatch_*_x64-setup.exe

Linux install: sudo apt install ./Dispatch_*.deb. For the AppImage, run chmod +x Dispatch_*.AppImage first.
